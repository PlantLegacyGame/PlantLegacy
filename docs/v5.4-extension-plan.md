# V5.4 Extension Plan

**Status:** approved 2026-11-09, not built, and not part of the v5.3.1
80-week gate plan. This document is the index and rationale; the task specs
themselves live in `DESIGN.md` Part 11 under "V5.4 extension tasks (approved
2026-11-09; not in the 80-week gate plan)".

**Purpose.** Record the ten requested world-simulation capabilities, map each
one onto the existing plant-organism design, and define the tasks that would
extend it. This is an extension, not a replacement: the player is still the
plant, the server is still authoritative, and the planet still remembers.

## 2. The reactive-fauna decision (request 5)

The earlier analysis said herbivores were "ambient events" because RULE_2
forbade intelligent NPCs and T06 defined herbivores as scripted ambient events.
That was too narrow. **Nothing is wrong with making them reactive.** What
RULE_2 actually protects is the absence of *intelligent* minds in multiplayer:
no conversation, no quests, no story goals, no judgment, no factions, no
strategic planning.

The v5.4 amendment allows **persistent, non-sapient fauna** that:

- have needs (hunger, thirst, fear, fatigue, herd);
- perceive local stimuli and coarse influence maps;
- answer with deterministic reflexes (graze, drink, flee, herd, struggle,
  attack, seek shelter);
- vocalize with animal sounds (growls, chirps, distress calls, warning cries,
  mating calls) — never human words or language;
- can be trapped, injured and killed by plants;
- can be tamed into a T11 companion.

They still may not use human words, converse, pursue story goals, exercise
judgment, form factions, use tools strategically, or plan. Conversation, story
goals and judgment remain campaign-only (T32). A distress call can attract
predators or alert nearby fauna, but that is a reflex chain, not intent.

**The python-vine case.** A carnivorous plant wraps vines around a herbivore.
The herbivore is now a real entity with health and a struggle reflex. The vine
applies damage through the T06 damage pipeline (source `plant`). The herbivore
struggles, damages the trapping nodes (source `herbivore`), and escapes if its
strength exceeds the trap strength. Either side can lose. This is exactly the
kind of emergent moment RULE_9 asks for, and it does not require an intelligent
NPC.

## 3. The no-reset decision (request 8)

World resets do not exist. A season-end calamity is a **burial**, not a wipe:
it kills plants and lays their traces under sediment. The planet, its terrain,
its material history and its fossilized player traces persist. O04 can archive
and restore a World, but there is no code path that returns a World to a blank
state. This is now written into RULE_8 and T20.

## 4. Rule amendments (approved 2026-11-09)

| Rule | Change | Why |
|---|---|---|
| RULE_2 | Allow persistent non-sapient fauna with needs, reflexes and animal vocalizations; keep intelligent NPCs campaign-only | Makes reactive herbivores legal without opening the door to NPCs |
| RULE_8 | State explicitly that there are no world resets; calamity is a burial | Matches the intended persistence |
| RULE_19 | Clarify that taming a fauna does not grant speech, human words, goals or judgment | Keeps companions inside the same ceiling |
| RULE_22 | Make the damage pipeline target-agnostic: plants and fauna share one record shape | Plant-vs-fauna combat needs one pipeline, not a parallel one |

The exact amended text is in `DESIGN.md` Part 2. The resolved approval items are
in `DESIGN.md` Part 16, items 9–14.

## 5. Task order

The tasks are post-alpha extensions. They do not enter the 24/52/80 gate plan.

```
T55 Material Simulation
  └─ T56 Volumetric Terrain
       ├─ C10 Volumetric Terrain and Material Rendering
       └─ T57 Parametric Terrain Features
            └─ T58 World Object Streaming and Behaviour

T54 Reactive Fauna
  └─ C11 Reactive Fauna Rendering

T59 Ecological Succession and Failsafes
  (needs T55, T20, T26, T39, T54)

O04 Cloud-Native World Orchestration
  (needs T03, T08C, O02, H01; only when a second World is actually needed)
```

T54 can run earlier than the rest because it only needs Gate 1 systems
(T01, T03, T06, T07). T58 is last because it generalizes the object model that
T55/T56/T57 produce.

## 7. What stays out

- **No intelligent NPCs in multiplayer.** No conversation, quests, story goals,
  judgment, factions, or planning. Campaign only.
- **No world resets.** No blank-state regeneration, no season wipe.
- **No arbitrary object scripting.** Behaviour is config-defined state machines,
  not uploaded code, `eval`, or client scripts.
- **No dense voxel database.** Terrain is sparse binary chunks, never one row
  per voxel.
- **No default microservices, queues, or Redis.** Many single-process Worlds,
  global accounts, and an ADR for any exception.
- **No named outcomes.** Parametric features and succession are general
  capabilities (RULE_7), not proper-noun structures or biomes.
- **No rarity fields.** RULE_20 still applies to every new item, material and
  species definition.

## 9. Honest cost

These are not small patches. T55 and T56 are each multi-week systems with
renderer, persistence, interest-management and performance work. T58 changes
the object model. T59 is a rules layer on top of T55 and T20. O04 is an ops
project, not a gameplay feature. T54 is the smallest and the best first slice
because it turns the existing scripted herbivore events into something players
can actually fight, trap, or flee from.

Do not start any of them while the current P0 blockers and `pnpm verify` are
red.
