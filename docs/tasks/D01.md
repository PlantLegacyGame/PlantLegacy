# D01: Dev Settings Engine

**Status:** `[x]` — Complete: `?dev=1` gate, server `/dev/config` endpoints, `config/dev.json`, DevPanel wired to server, persistence switch wired to disconnect logic, key binding added.
**Scope:** A dev-only console that exposes every config system and the key game switches, so behaviour is explicit and editable instead of inferred from hidden client state.
**Owner:** `config/` + `apps/client` + `apps/server`
**Dependencies:** T00, C01, T00A, T01

---

## 1. Why

The 2026-11-07 audit found implicit behaviour that could not be inspected or
changed from inside the game:

- persistence vs session-only play was a hidden client/server key detail;
- germination gate thresholds were unused;
- auto-growth was not a visible switch;
- camera framing, seed scale and plant size class were hardcoded;
- growth costs lived in both config and client code.

ADR-029 makes the default local/dev path session-only and moves every switch
behind an explicit dev surface.

## 2. Required behaviour

1. The client opens the console with `?dev=1` (and a key binding once defined).
2. The console lists every loaded config file and every value with its current
   value, type, range and notes.
3. Values can be edited and applied without editing source files.
4. The key game switches are first-class toggles:
   - persistence (off by default)
   - reconnect window
   - auto-growth (off by default)
   - germination gate
   - germination failure kills the seed
   - plant size class (normal / large / giant)
   - camera start/recenter distance and pan speed
   - resource rates and photo/upkeep rates
   - WebGPU on/off and LOD thresholds
5. A reset action restores the checked-in defaults.
6. The endpoint is dev-only. In production it returns 404 and cannot change
   config.
7. The console never becomes a way for a normal player to cheat in production.

## 3. Implementation Summary (2026-11-10)

### Client (`apps/client/src/main.ts`)
- `?dev=1` query parameter gate controls DevPanel visibility
- DevPanel created only when `isDevMode = new URLSearchParams(location.search).has('dev')`
- Tab key binding added to toggle DevPanel (backtick remains for debug overlay)

### Server (`apps/server/src/ops/dev.ts`)
- `GET /dev/config` — returns flattened dev config (404 in production)
- `POST /dev/config` — validates and updates dev config values (404 in production)
- `validateConfigValue()` — validates against schema (type, range, enum)
- `loadDevConfig()` — loads dev.json and returns Map of ConfigEntry

### Server (`apps/server/src/main.ts`)
- `handleDevAction()` extended with `dev_set_config` action for:
  - `auto_growth`
  - `germination_gate`
  - `germination_failure_kills_seed`
  - `persistence_enabled`
  - `seed_size_class` (client-side only)
- `World.setPersistenceEnabled()` recreates reconnect state machine
- `reconnect_window_ms` added to `net_proto.json`

### Client (`apps/client/src/ui/DevPanel.ts`)
- `loadConfig()` fetches from `/dev/config` and applies to UI
- `resetToDefaults()` POSTs reset to server and reloads
- All boolean switches now have toggles with `data-config-key` attributes
- New "Game Switches" tab in Simulation with:
  - Auto Growth toggle
  - Germination Gate toggle
  - Germination Failure Kills Seed toggle
  - Persistence Enabled toggle
  - Seed Size Class select (normal/large/giant)
- "Reset to Defaults" button in header

### Config (`config/dev.json`)
Created with all dev settings:
- `dev_panel_enabled`, `persistence_enabled`, `reconnect_window_seconds`
- `auto_growth`, `germination_gate`, `germination_failure_kills_seed`
- `seed_size_class`, camera distances, pan speed
- `resource_rates` object with photosynthesis/upkeep/growth rates
- `webgpu_enabled` and LOD thresholds

## 5. Config Tunables (`config/dev.json`)

| Tunable | Type | Range / Options | Default | Effect |
|---|---|---|---|---|
| `dev_panel_enabled` | boolean | `true`/`false` | `true` | Master switch for dev panel |
| `persistence_enabled` | boolean | `true`/`false` | `false` | Plant persist across disconnects |
| `reconnect_window_seconds` | integer | [30, 86400] | 300 | Reclaim window when persistence on |
| `auto_growth` | boolean | `true`/`false` | `false` | Seeds auto-germinate without player |
| `germination_gate` | boolean | `true`/`false` | `true` | Require moisture/light for germination |
| `germination_failure_kills_seed` | boolean | `true`/`false` | `true` | Failed germination destroys seed |
| `seed_size_class` | enum | `normal`/`large`/`giant` | `normal` | Initial plant/camera scale |
| `camera_start_distance` | number | [5, 200] | 26.0 | Initial camera distance |
| `camera_recenter_distance` | number | [5, 200] | 18.0 | Space recenter distance |
| `camera_pan_speed` | number | [0.5, 50] | 5.0 | WASD/arrow pan speed |
| `webgpu_enabled` | boolean | `true`/`false` | `true` | WebGPU render path |

## 6. Verification

- `pnpm verify`: lint, typecheck, config validation, and all 181 unit tests pass.
- `?dev=1` opens panel; absent without flag.
- Production server returns 404 for `/dev/config` endpoints.
- Persistence off: disconnect removes plant immediately.
- Persistence on: reconnect window works.
- Auto-growth off: germination requires player commit.
- Auto-growth on: germination proceeds without commit.
- Germination gate values visible in DevPanel before commit.

## 7. Not in v1

- Remote admin auth and multi-operator audit logs.
- Editing compiled shaders or arbitrary source from the browser.
- A level editor or terrain sculpting.
