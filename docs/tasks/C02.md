# C02 — Procedural Plant Renderer v1 (The Unified Organism)

**Status:** `[x]` Complete. Built with Raymarched Signed Distance Fields (SDF) and polynomial smooth minimum (`smin`) organic fusion inside local bounding volumes, implementing the procedural creature architecture from *Hatched* by SublimeOrange (`https://www.reddit.com/r/IndieDev/comments/1x9mmly/im_a_solo_dev_building_hatched_a/`, `https://sublimeorange.itch.io/hatched`). All modular primitives (tapered capsules, joint spheres, root crowns, parametric leaf blades) fuse into a single continuous anatomical membrane without clipping seams or floating parts.
**Phase:** 1 — The Living Sprout. **Depends on:** C01, T01.
**Config owner:** `config/plant_renderer.json` (active).

## Architecture & Scope

### 1. The Core Vision: Modular Primitives Fused into a Single Living Organism
- Player plants are constructed from modular mathematical primitives (tapered capsules, joint spheres, root crowns, parametric leaf blades).
- Instead of rendering as separate, disjointed polygon cylinders with flat caps clipping into each other, the renderer treats the plant as a **continuous, unbroken anatomical membrane**.
- Neighboring primitives are fused using the polynomial smooth minimum operator (`smin`), forming smooth organic branch collars, fillets, and seamless root-to-canopy transitions at the ground plane ($y = 0$).

### 2. Raymarched Signed Distance Fields (SDF) in Local Bounding Volume
- **Bounding Box Execution:** The raymarching fragment shader executes inside a bounding box geometry tightly enclosing the plant's active node graph plus blend padding. Pixels outside the volume never evaluate ray steps, guaranteeing 60 fps desktop performance.
- **Tapered Capsule SDF (`sdCapsule`):** Swept tapered segments between parent node $\mathbf{a}$ and child node $\mathbf{b}$ with radii $r_a, r_b$ derived from node biomass:
  $$\text{sdCapsule}(\mathbf{p}, \mathbf{a}, \mathbf{b}, r_a, r_b) = \| (\mathbf{p} - \mathbf{a}) - (\mathbf{b} - \mathbf{a}) \cdot h \| - \text{mix}(r_a, r_b, h)$$
- **Joint Spheres (`sdSphere`):** Padding spheres at node junctions and an anchoring root-crown ellipsoid at $y = 0$.
- **Smooth Minimum Operator (`smin`):**
  $$\text{smin}(a, b, k) = \text{mix}(b, a, h) - k \cdot h \cdot (1.0 - h), \quad h = \text{clamp}(0.5 + 0.5 \cdot (b - a) / k, 0.0, 1.0)$$
  where $k$ is the tunable blend radius (`smin_blend_radius` in `plant_renderer.json`).
  Smoothly interpolates distance $d$, tissue type (root vs stem vs leaf), tissue health, and player ownership (`isOwnPlant`).
- **Screen Depth Integration:** Writes calculated hit distance to `gl_FragDepth` so the raymarched plant tests and occludes accurately against the terrain, ground plane, and Three.js scene objects.
- **Normal Calculation:** Computed via central differences gradient $\nabla d(\mathbf{p})$.

### 3. "One Shader to Bind Them All" (Material & Lighting)
- **Continuous 3D Triplanar Noise:** 4-octave Fractional Brownian Motion (fbm) noise perturbs color and normals in world space, eliminating UV distortion or seams at branch joints.
- **Procedural Wind Displacement:** Coherent 3D wind field displaces query coordinates prior to distance evaluation; sway amplitude scales with height $y$.
- **Translucent Foliage & PBR-Lite Shading:** Subsurface transmission approximation through thin leaf parts and tender green shoots, directional sunlight with hemispheric ambient light, and rim lighting.
- **Three Mutation Visual Signatures:**
  - `mutation0`: Bioluminescent emissive glow.
  - `mutation1`: Thickened bark (scaling capsule radius).
  - `mutation2`: Variegated foliage pigmentation.

### 4. Root Sight Integration (T02)
- Roots ($y < 0$) and stems/trunk ($y > 0$) are parts of the exact same continuous SDF body.
- In Root Sight mode, the ground cutaway shader reveals the underground root branches of this single organism, illuminating viewer roots in `own_root_highlight_color` (#4CAF50) and rival roots in `rival_root_highlight_color` (#FF5722).

## Config Tunables (`config/plant_renderer.json`)

| Key | Type | Range | Default | Effect |
|---|---|---|---|---|
| `max_nodes_per_plant` | integer | 100–10000 | 1000 | Maximum nodes per plant |
| `smin_blend_radius` | number | 0.02–0.5 | 0.08 | Organic fusion blend radius ($k$) between primitives (tuned to eliminate joint lumps) |
| `max_raymarch_steps` | integer | 16–128 | 32 | Maximum sphere tracing steps per ray |
| `raymarch_hit_epsilon` | number | 0.001–0.05 | 0.005 | Surface hit detection threshold |
| `node_spacing_min` | number | 0.1–5.0 | 0.5 | Minimum distance between nodes |
| `node_spacing_max` | number | 0.5–10.0 | 2.0 | Maximum distance between nodes |
| `branch_probability` | number | 0.0–1.0 | 0.15 | Branching probability per node |
| `wind_strength` | number | 0.0–2.0 | 0.3 | Amplitude of wind displacement |
| `wind_speed` | number | 0.1–5.0 | 1.0 | Frequency of wind displacement |
| `health_tint_strength` | number | 0.0–1.0 | 0.5 | Strength of desaturation on damaged tissue |
| `mutation_visual_0_param`| number | 0.0–5.0 | 1.0 | Emissive intensity for bioluminescence |
| `mutation_visual_1_param`| number | 0.5–3.0 | 1.5 | Bark thickness multiplier |
| `mutation_visual_2_param`| number | 0.0–1.0 | 0.3 | Variegated color variation strength |
