## Scope delivered

### Server-side growth simulation (`apps/server/src/ops/plantWorld.ts`)
- `PlantWorld.createPlant()`: creates plant with root node at player spawn position
- `PlantWorld.tryGrow()`: grows a typed node (root/stem/leaf/flower/spore_sac/vine) from parent node, validates biomass cost, layer crossing, growth cooldown, world bounds
- `PlantWorld.step()`: processes upkeep (biomass drain), root overlap pressure damage between rival plants
- `PlantWorld.processRootOverlapDamage()`: rival root nodes in overlapping space apply pressure damage at config rate
- `PlantWorld.processRootAttack()`: directed root attack deals extra damage to rival roots
- `PlantWorld.getCanopyShadingAt()`: canopy nodes lower light on tiles below
- `processGrowthIntents()` in `main.ts`: validates and applies GROWTH_INTENT from clients, broadcasts GROWTH_EVENT with new node

### Client-side growth (`apps/client/src/main.ts`)
- `GROWTH_INTENT` (type 4) sending on 'G' key: grows from root node in camera forward direction
- `GROWTH_EVENT` (type 16) handling: applies server-broadcast new node to plant node map
- `WelcomePayload` includes `rootNode` with position, type, biomass
- `PlantRenderer.updatePlantData()` receives real plant nodes from server (replaces `generateTestPlant()` test data)
- Type mapping: root→0, stem→1, vine→2, leaf/flower/spore_sac→3

### Growth simulation

| Criterion | Evidence | Result |
|---|---|---|
| Plant visibly grows in both layers | `tryGrow()` creates nodes with type/layer; root layer = underground, canopy = above ground | pass |

| Growth interrupted by damage | Root overlap pressure damage reduces biomass; `step()` removes plant when biomass depleted | pass |

| No hardcoded values | All tunables in `config/growth.json` (speed, cost, cooldown, pressure, light blocking) | pass |

## Manual verification

- Connect to server, receive WELCOME with plantId and rootNode
- Press 'G' to grow a stem from root node in camera direction
- Server responds with GROWTH_EVENT containing new node
- Client renders new node as tapered tube with instanced leaves
- Press 'G' repeatedly to grow more nodes; observe biomass cost and cooldown

## Known limitations

- Growth direction is camera-based, not explicit two-step pointing (planned for T01 full interaction)
- Client grows from root node only; no node selection UI yet
- Offline plant simulation (Part 13.6 tiers) not yet implemented
- Plant data not persisted (T03 will add persistence)
- `generateTestPlant()` removed from client; plant renders only from server data
