## Acceptance criteria

| Criterion | Result |
|---|---|
| Uprooting visible and broadcast | Met: the server applies a rigid lift/lean/tumble to every node and broadcasts `PLANT_UPROOT` (39) with node positions; clients redraw the moved nodes. Not eye-verified this session. |
| Reroot stressful but possible via crawl | Met: `REROOT_INTENT` (37) steers the crawl; settling needs continuous valid soil inside `reroot_window_s`. |
| Failure death | Met: once the window closes the crawl cannot settle and the uprooted drain starves the plant (`cause: starvation`). |
| All damage uses one pipeline | Met: weather, tool, scripted herbivore and terrain-collapse damage all enter `DamagePipeline.applyDamage`. |
| Tool source accepted | Met: `dev_damage_plant` / `applyToolHit`; no player-facing tool verb ships (DESIGN C04 owns that UI). |
| Herbivores are scripted events, not agents | Met: a timed swarm with a fixed centre and radius; no pathfinding. |
| Fragment drops and remains work and expire | Met at the world level: dropped fragments, remains and dung carry expiry times and are broadcast/removed. Items themselves stay T08A/T51. |

## State machine

```
rooted ──(saturation | gust | collapse | structural damage)──▶ uprooted
uprooted ──(first physics step)──▶ tumbling ──(settled)──▶ uprooted
uprooted/rerooting ──(reroot intent)──▶ rerooting ──(settle timer)──▶ rooted
uprooted/tumbling/rerooting ──(mass drained to zero)──▶ dead (starvation)
```

- `uprooted` is both the "just ripped" state and the settled state after the
  tumble; `tumbling` is the physics phase between them. The visible lean and
  offset are recomputed from a captured base pose every tick, so a long tumble
  cannot accumulate drift and a reroot can stand the plant back up.
- A rerooted plant is placed at the crawled root position on the terrain height
  and its base pose is translated there; the old uproot state is discarded.
- T04's `movement.rerootSpeed` multiplies the crawl speed, closing the T04
  movement-block acceptance item. The T02 substrate multiplier is still 1.0:
  no substrate signal exists in the terrain service yet.

## Damage sources

| Source | Signal | Tuning |
|---|---|---|
| weather | active thunderstorm continuous exposure, plus lightning strikes | `weather_damage_per_s`, `storm_gust_speed_mps`, `lightning_damage_amount` |
| tool | accepted server call; no MVP verb | `tool_damage_per_hit` |
| herbivore | timed swarm event over a fixed region | `herbivore_swarm_*` |
| terrain | a collapse edit under the root plate; landing impacts during a tumble | `terrain_collapse_*`, `terrain_collapse_damage`, `tumbling.impact_*` |

Roots are **not** a source (ADR-051). Damage picks the most exposed tissue first
(leaves, flowers, spores → stems and trunk → storage → roots → seed), detaches a
part when its mass reaches zero, and keeps the graph connected by re-parenting
the part's children.

Damage accumulates as unhealed structural damage: `damage_memory_decay_per_s`
bleeds it away, and crossing `uproot.damage_threshold_hp` tears the plant free.
"The plant's HP" is its structural biomass, so the configured threshold is
capped at 80% of the plant's own mass — a seedling can still be uprooted instead
of being exempt because it can never reach a large absolute number.

## Uproot causes

- **Saturation.** The root tile at or above `saturation_uproot_moisture` while it
  is actually raining, continuously for `saturation_uproot_seconds`. Ordinary
  damp soil does not count and the counter resets when the tile drains.
- **Gust.** During the active storm phase, `storm_gust_speed_mps` is scaled by
  exposed height against `gust_height_reference_m`; crossing
  `gust_uproot_threshold_mps` tears the plant out. A short seedling survives a
  gust that takes a tall plant.
- **Collapse.** A collapse edit within `collapse_uproot_radius_m` of the root
  plate.
- **Structural damage.** Accumulated damage crossing the threshold above.

There is no random uproot and no desperation buff (ADR-052).

## Drops and kill credit

- A part destroyed by damage drops a fragment with `fragment_drop_chance`.
- A death leaves `remains_fragment_count` remains and `dung_per_death` dung.
- A swarm leaves `dung_per_swarm` dung when it moves on.
- Fragments/remains use `fragment_lifetime_s`, dung uses `dung_lifetime_s`.
- Every creditable hit (a source with a player or plant id) is remembered for
  `kill_credit_window_s`; on death the largest total is credited and
  `KILL_CREDIT` (43) is broadcast. Weather and herbivores credit nobody.

Drops are world objects with an id, kind, position and expiry. They are not
inventory items: T08A's inventory is in-memory scaffolding and T51 owns fragment
item rules (ADR-056).

## Protocol

| Type | Direction | Payload |
|---|---|---|
| 37 `REROOT_INTENT` | client → server | `{ dirX, dirZ }` |
| 38 `PLANT_DAMAGE` | server → client | source, amount, destroyed node ids, remaining biomass |
| 39 `PLANT_UPROOT` | server → client | phase, cause, root position, tilt/heading, window left, node positions |
| 40 `DROP_SPAWN` | server → client | drop id, kind, position, expiry |
| 41 `DROP_EXPIRED` | server → client | drop id |
| 42 `FAUNA_EVENT` | server → client | swarm start/end, centre, radius |
| 43 `KILL_CREDIT` | server → client | plant id and credited source |

`PLANT_UPROOT` uses node positions rather than a client-side transform so the
client never has to model the base pose. The transform is throttled to four
broadcasts a second. `PLANT_DAMAGE` is coalesced per plant and sent at most
twice a second (immediately when a part is destroyed or the plant dies), because
weather hits every plant on every tick and one message per hit was 20 broadcasts
a second per plant.

## Persistence

PLNT snapshots move to **v3**: an optional uproot block (phase, cause,
`sinceTick`, accumulated damage). A restored uprooted plant adopts its saved node
positions as the new base pose and starts settled, rather than replaying a fall
that had already finished. v1 and v2 snapshots still load. The world boot path
now carries mutation and uproot fields through when rebuilding a plant.

## Known gaps

- Tumbling integrates against a ground plane at y = 0, not the shared terrain
  height field, so a fall on a steep slope is not conformed to the surface. The
  reroot itself does use `terrain.heightAt`.
- The T02 crawl substrate multiplier is fixed at 1.0.
- Since 2026-11-15 (C04 slice), the player steers the crawl with a D-pad or
  WASD/arrows while uprooted, and the HUD shows phase, health, damage and the
  reroot window. A seed that has not germinated cannot be uprooted at all:
  there is no root plate yet, and ordinary rain must not start a starvation
  clock on a plant the player has only just planted. Saturation uproot is
  limited to `thunderstorm_active`; `rain` wets the soil without tearing plants
  out. Automatic herbivore swarms are disabled until T54 renders fauna;
  `dev_herbivore_swarm` still forces one. Drops are drawn and collectable since
  2026-11-20 (`renderers/WorldDrops.ts`, `ops/dropPickup.ts`); their Postgres
  persistence remains with T08A.
