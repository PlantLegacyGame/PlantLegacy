## Scope delivered

- `config/onboarding.json` with 3 values: `hint_card_lines`, `show_hint_card_duration_ms`, `resource_tooltips`.

- No client-side resource writes.

## Config: `config/resources.json` (status `active`)

| Key | Type | Range | Default | Effect |
|---|---|---|---|---|
| `tile_size` | number | 0.5–10 | `1.0` | World units per tile |
| `grid_width` | integer | 16–1024 | `256` | Number of tiles along X |
| `grid_height` | integer | 16–1024 | `256` | Number of tiles along Z |
| `tile_light_base` | integer | 0–100 | `80` | Base light level from sun |
| `day_night_curve` | array of number | 32 entries | 32-value curve | Day/night multiplier curve |
| `tile_moisture_base` | integer | 0–100 | `40` | Base moisture level |
| `rain_gain_per_s` | number | 0–5 | `0.5` | Moisture gain per second during rain |
| `evaporation_per_s` | number | 0–1 | `0.1` | Moisture loss per second |
| `tile_minerals_base` | integer | 0–100 | `30` | Base mineral level |
| `absorption_per_s` | number | 0–5 | `0.2` | Minerals/moisture absorbed by roots per second |
| `absorption_radius` | number | 1–50 | `2.0` | Radius in tiles for root absorption |
| `dead_root_deposit` | number | 0–50 | `5.0` | Minerals deposited per dead root node |
| `dead_plant_deposit` | number | 0–50 | `20.0` | Minerals deposited per dead plant |
| `dung_deposit` | number | 0–50 | `15.0` | Minerals deposited by dung |
| `fertilizer_deposit` | number | 0–50 | `25.0` | Minerals deposited by fertilizer |
| `photosynthesis_rate` | number | 0–1.0 | `0.1` | Base photosynthesis rate |
| `light_factor_curve` | array of [x,y] | 5 points | piecewise-linear | Light factor curve (unused in formula) |
| `moisture_factor_curve` | array of [x,y] | 5 points | piecewise-linear | Moisture factor curve |
| `mineral_factor_curve` | array of [x,y] | 5 points | piecewise-linear | Mineral factor curve |
| `consumption_trigger_tile_mineral_threshold` | integer | 0–100 | `20` | Tile mineral threshold for consumption trigger |
| `consumption_trigger_dung_item` | boolean | — | `true` | Enable dung consumption trigger |
| `consumption_trigger_fertilizer_item` | boolean | — | `true` | Enable fertilizer consumption trigger |
| `diffusion_rate` | number | 0–0.1 | `0.01` | Resource diffusion rate between tiles |
| `max_absorption_per_tick` | number | 0–10 | `1.0` | Maximum absorption per tick |
| `canopy_shade_reduction` | number | 0–1 | `0.1` | Light reduction per canopy node |
