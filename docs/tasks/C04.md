# C04 — HUD and Controls v1

**Status:** `[~]` **partial.** The body-state HUD, health wording, reroot
controls, Inspect/Inventory side panels, Settings sheet and death-screen stats
are implemented and verified by unit tests and the full build. Rebinding and
the notification log are still not built. The in-browser checklist has not
been run because the game runs in the director's own Chrome, which this agent
cannot inspect.

**Depends on:** C01, T00A, T07, T05, T06. **Blocks:** C05.

## Implementation summary

- **Plant status HUD** (`apps/client/src/ui/PlantStatusHud.ts`), DOM, top
  centre, hidden until the server confirms an own plant:
  - biomass and a signed biomass-per-second rate derived from consecutive
    authoritative totals (smoothed, reset across gaps > 2 s);
  - state: the health word when rooted (Healthy / Stressed / Withering /
    Dying), otherwise the phase word (Uprooted / Tumbling / Rerooting);
  - health bar as remaining damage against the uproot ceiling
    (`1 - damageHp / threshold`), with the percentage written out;
  - energy, water and minerals against their capacities, and live node count;
  - mutation count with the two bills kept separate (`0.30 E/s · 0.10 B/s`);
  - day number and clock (`Day 3 · 18:40`) plus weather word and the
    next-state forecast with a countdown. One in-game day is one real hour
    (`config/daynight.json`), with minutes running faster in-game.
- **Inspect / Inventory panels** (`apps/client/src/ui/PlayerPanels.ts`): `I`
  opens both. Inspect is fixed on the left, inventory on the right, and the
  world stays visible in the middle. Inspect carries the body stats, the
  mutation list (moved out of the old mutation panel, with kind, separate
  energy/biomass bills, share bar, total and growth-pressure bars) and a per-node health
  list (Growing / Intact / Fading / Depleted / Gone) sorted root-first. The
  inventory grid talks to the existing server inventory messages and never
  owns item state. Panels cover overlapping HUD pieces and restore them on
  close.
- **Settings sheet** (`apps/client/src/ui/SettingsPanel.ts`): two tabs. Settings
  holds a text-size slider and reduced motion; Controls is generated from the
  live bindings with action, keys, mouse and mode. Opened with the gear button
  or `O` (`settings_toggle`), Esc closes.
- **Death stats** (`apps/client/src/ui/EntryScreen.ts`): the plant-lost screen
  shows the same body rows as Inspect, plus the server death cause.
- **Reroot controls** appear only while `uprooted`/`rerooting`: a five-button
  pad (forward, left, stop, right, back) and the reroot window countdown. While
  uprooted, WASD/arrow movement actions steer the crawl instead of panning the
  camera (DESIGN 18.1.2); the direction is camera-relative and the server keeps
  the last direction until it changes.
- **Damage feedback:** a brief edge vignette (not a screen-wide flash), a
  rate-limited factual toast, and an immediate structure update. The server now
  includes `damageHp` and `structuralThreshold` in `PLANT_DAMAGE` and
  `structure` in `STATE`/`KEYFRAME`, so the HUD never guesses.
- **Death handoff:** the toast stack is cleared and new toasts are suppressed
  when the plant-lost screen opens, so no damage or state notification appears
  under a plant that no longer exists.
- Text updates are capped by `ui.hud_update_interval_ms` (10 Hz by default),
  matching DESIGN 18.2.
- The panel is plain data and never edits plant state; reroot requests are
  intents (`REROOT_INTENT`) and the server owns the crawl.

## Config files touched

| File | Change |
|---|---|
| `config/ui.json` | `hud_update_interval_ms`, `damage_vignette_ms`, `health_healthy_fraction`, `health_stressed_fraction`, `health_withering_fraction` |
| `config/controls.json` | `settings_toggle` binding (`KeyO`); `camera_pan_*` actions are reused as reroot steering while uprooted |
| `config/damage.json` | `herbivore_swarm_auto_enabled` false so an invisible swarm cannot kill a spawn |

## Tunables

| Key | Type | Range | Default | Effect |
|---|---|---|---|---|
| `ui.hud_update_interval_ms` | integer | 50–1000 | 100 | Minimum time between plant-status text updates |
| `ui.damage_vignette_ms` | integer | 100–2000 | 420 | Edge-vignette length on damage |
| `ui.health_healthy_fraction` | number | 0–1 | 0.75 | Health at or above this reads Healthy |
| `ui.health_stressed_fraction` | number | 0–1 | 0.5 | Health at or above this reads Stressed |
| `ui.health_withering_fraction` | number | 0–1 | 0.25 | Health at or above this reads Withering, below reads Dying |
| `damage.herbivore_swarm_auto_enabled` | boolean | — | false | Automatic (invisible) herbivore swarms; dev-forced swarms still work |

## Server changes

- `DamagePipeline.getStructure()` returns `{ damageHp, threshold }` using the
  same `uprootDamageThreshold` rule that decides an uproot.
- `PLANT_DAMAGE` carries `damageHp` and `structuralThreshold`.
- `STATE`/`KEYFRAME` plant entries carry `structure` for the owner.

## Manual checklist (not run)

In the director's Chrome, with `?dev=1`:

1. Spawn a plant. The top-centre panel shows `Healthy`, biomass, rate,
   `Health 100%`, and the day/weather line with a day number.
2. Press `I`. Inspect opens on the left and inventory on the right, the world
   stays visible between them, and the mutation list is inside Inspect.
3. Look at the node rows. Each growing node has its own health word and bar.
4. Press `I` again, or Esc. Both panels close and the chat/readout come back.
5. Open Settings with the gear or `O`. Switch between Settings and Controls;
   move the text-size slider and watch the UI scale.
6. Dev Panel → Plant → **Tool Hit**. Health falls, the edge vignette pulses,
   one damage toast appears, biomass drops.
7. **Force Uproot**. State changes to `Uprooted`/`Tumbling`, the reroot window
   counts down, and the D-pad appears.
8. Hold a D-pad direction or W/A/S/D. The plant crawls in that camera-relative
   direction; releasing sends stop.
9. Release near moist soil and wait. State returns to `Healthy`, the controls
   disappear, and the toast says `Rooted again.`
10. Force uproot again and let the window expire. The plant starves and the
    death screen shows the same stats rows plus the death cause.

Known visual risks to check: the top-centre panel may crowd the chat on very
narrow windows; the vignette and toast must not fire continuously in a storm.

## Known gaps

- No rebinding screen yet; the Controls tab is read-only.
- No notification log; damage/uproot use toasts.
- Spores/session/booster rows are absent because their systems are not built.
- No render interpolation between server ticks yet (improvement plan 2-B).
- Health is the structural damage fraction, not a separate hit-point pool
  (ADR-055); a fully healthy plant can still be uprooted by a large hit.
