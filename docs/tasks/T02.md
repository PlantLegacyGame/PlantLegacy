# T02 — Root Sight

**Status:** `[x]` Complete. Two-mode camera with subterranean elevation, organic root-envelope ground cutaway shader, and natural botanical subterranean visualization fully integrated with the plant rendering pipeline (C02 WebGL SDF & C02b WebGPU). Underground roots maintain their natural botanical colors, revealed through smooth organic cavities ("air bubbles") carved along underground growths.
**Phase:** 1 — The Living Sprout. **Depends on:** T01, C01.
**Config owner:** `config/root_sight.json` (active).

## Scope delivered

### Soil cutaway shader & camera mode (`apps/client/src/main.ts`, `ground.wgsl`, `EnvironmentRenderer.ts`)
- **Independent camera entity**: camera orbits, zooms, and pans with OrbitControls without affecting the plant.
- **Subterranean camera tilt**: when Root Sight is active, `maxPolarAngle` smoothly extends to `Math.PI - 0.05`, allowing players to tilt the camera beneath the soil line ($y < 0$) to inspect root geometry from underground angles.
- **Organic envelope cutaways ("air bubbles" through soil)**: ground cutaways are not a generic flat circle; shaders evaluate smooth minimum distance (`smin`) across all subterranean root nodes and underground elements (of player and rival plants). Dirt opens up along the actual branching paths of underground growths like smooth organic envelopes, with dithered smooth edges and earthen rim shading.
- **Smooth transition**: linear progress state updated with delta time over `transitionMs` (500 ms default), eased using cubic ease-out `1 - (1 - t)^3`. Reverses cleanly mid-transition.
- **Automatic activation on subterranean growth**: selecting a subterranean growth option (radicle, root, lateral root) or focusing on a subterranean node automatically engages Root Sight and centers the camera on the target node.
- **Local-only state**: toggling Root Sight does not send network messages or alter server state. Other players cannot detect when a player is in Root Sight (RULE_4, RULE_27).

### Root shader visualization (`PlantRenderer.ts`, `common.wgsl`, `mesh.wgsl`, `WebGPURenderer.ts`)
- **Natural botanical coloration**: roots underground retain their natural bark and root colors under regular Root Sight; visibility is achieved organically by peeling back soil envelopes rather than neon recoloring.
- **Subterranean node aura buffer**: passes up to 64 underground node positions and radii via 1D texture (`rootAuraTexture`) to both WebGPU and WebGL pipelines for unified distance evaluation.
- **Multi-node support**: tracks all underground growths across player and rival plants for complete subterranean situational awareness.

### Config and server route (`config/root_sight.json`, `apps/server/src/main.ts`, `apps/client/src/config/clientConfig.ts`)
- `config/root_sight.json`: active extended-1 schema config with cutaway radius, transition ms, soil opacity, highlight colors, substrate multiplier, and camera target.
- `apps/server/src/main.ts`: serves `GET /config/root_sight` reading runtime config with fallbacks.
- `apps/client/src/config/clientConfig.ts`: `loadRootSightConfig` loads and normalizes snake_case to camelCase.
- `apps/client/src/main.ts`: subscribes `root_sight_toggle` action from `config/controls.json` (`Tab` key).

## Config: `config/root_sight.json` (status `active`)

| Key | Type | Range | Default | Effect |
|---|---|---|---|---|
| `cutaway_radius` | number | 5–500 | 50.0 | Radius of underground cutaway sphere |
| `transition_ms` | integer | 0–3000 | 500 | Transition duration between modes (ms) |
| `soil_opacity` | number | 0.0–0.9 | 0.3 | Opacity of soil inside the cutaway |
| `own_root_highlight_color` | color | — | `#4CAF50` | Highlight color for local player's roots |
| `rival_root_highlight_color` | color | — | `#FF5722` | Highlight color for rival players' roots |
| `substrate_multiplier` | number | 0.1–1.0 | 0.5 | Physics movement multiplier for uprooted crawl (T06) |
| `camera_target` | enum | own_plant, camera_position | `own_plant` | Center reference for cutaway sphere |
