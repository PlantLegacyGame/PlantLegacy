## Scope delivered

### Input abstraction (`apps/client/src/input/InputBus.ts`)
- Named actions from DESIGN.md 17.2/17.4 (camera_orbit, camera_pan, camera_zoom, camera_recenter, camera_rotate_left/right, select_part, grow_cancel, root_sight_toggle, reroot_steer, emote_wheel, growth_intent, inventory_open, mutations_panel, chat_open, menu_open, debug_toggle)
- Producers: keyboard (keydown/keyup), mouse (mousedown/mouseup/wheel)
- Bindings loaded at runtime from `/config/controls` (snake_case→camelCase mapping)
- Context rules (D-15): modal > text input > context actions > camera
- Gameplay code reads action state via `isActive(actionId)`, never raw keys

### UI shell (`apps/client/src/ui/UIShell.ts`)
- Layer stack with z-index from `config/ui.json`: world (0), hud (100), panel (200), menu (300), modal (400), toast (500), tooltip (600), debug (700)
- Theme tokens as CSS variables on `:root` (loam_900, bark_700, bone_100, bone_300, leaf_500, sprout_300, ember_500, sky_400, soil_600)
- Global text-scale CSS variable (`--text-scale`) with range 80–150%
- Toast notifications with auto-dismiss, max stack, kind styling
- Panel open/close events with title

### Quality controller (`apps/client/src/render/QualityController.ts`)
- Tier selection by hardware concurrency + touch capability
- Dynamic pixel-ratio scaling toward `resolution_floor` when fps < `fps_warning_threshold` × `target_fps`
- Tier budgets: low (1.0 DPR, 50k tri), medium (1.5 DPR, 200k tri), high (2.0 DPR, 500k tri)
- No per-frame allocations

### Debug overlay (`apps/client/src/ui/DebugOverlay.ts`)
- fps, frame ms, triangles, draw calls, JS heap memory (MB), network KB/s in/out, device pixel ratio
- Toggled by backtick key (configurable via `debug_overlay_key`)
- Sampled ~4×/s, DOM reused (no per-frame allocations)

### Client config loader (`apps/client/src/config/clientConfig.ts`)
- Loads `render.json`, `controls.json`, `ui.json` from server `/config/*` routes
- Maps snake_case server response to camelCase client interfaces

### Server config routes (`apps/server/src/main.ts`)
- `GET /config/render` — quality tiers, camera smoothing, idle-drop timeout, debug toggle
- `GET /config/controls` — bindings, touch targets, text scale, context dock fade
- `GET /config/ui` — theme tokens, layer z-indexes, toast/panel defaults, hint card

### Main rewire (`apps/client/src/main.ts`)
- `initC01()` called before connect; builds InputBus, UIShell, DebugOverlay, QualityController
- Keyboard/mouse producers wired to InputBus
- Growth intent (`G` key) dispatched via InputBus subscription
- Visibility change handler pauses detail updates when tab hidden

## Config: `config/render.json` (status `active`)

| Key | Type | Range | Default | Effect |
|---|---|---|---|---|
| `target_fps` | integer | 30–120 | 60 | Render-loop target FPS |
| `fps_warning_threshold` | number | 0.5–0.95 | 0.85 | Fraction of target_fps triggering quality drop |
| `resolution_floor` | number | 0.1–1.0 | 0.25 | Minimum pixel ratio relative to devicePixelRatio |
| `max_pixel_ratio` | number | 1.0–4.0 | 2.0 | Maximum pixel ratio |
| `camera_smoothing` | number | 0.0–0.5 | 0.05 | OrbitControls dampingFactor |
| `camera_min_distance` | number | 1.0–100.0 | 10.0 | Minimum orbit distance |
| `camera_max_distance` | number | 50.0–1000.0 | 200.0 | Maximum orbit distance |
| `camera_max_polar_angle` | number | 0.0–3.14 | 1.52 | Max polar angle (radians) |
| `idle_drop_timeout_ms` | integer | 0–120000 | 30000 | Ms of no input before throttling |
| `shadow_map_size` | integer | 512–4096 | 2048 | Directional light shadow map dimension |
| `debug_overlay_enabled` | boolean | — | true | Toggle debug overlay |
| `debug_overlay_key` | string | max 8 | \` | Key that toggles debug overlay |
| `pause_on_hidden` | boolean | — | true | Pause render loop when tab hidden |
| `quality_tiers` | schema_array | — | 3 tiers | Tier definitions (name, pixel_ratio, shadow_map_size, max_triangles, antialiasing) |
