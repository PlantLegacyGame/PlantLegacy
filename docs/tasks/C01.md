## Scope delivered

- Vite 8 + Three.js r187 client, `@vitejs/plugin-legacy`, `base:
  '/PlantLegacy/'` for GitHub Pages.
- Vite dev server on port 4173 with proxies for `/health`, `/ready`, `/config`
  and `/ws`.
- Three.js scene, perspective camera, `OrbitControls` (orbit, pan, zoom,
  damping), ambient/directional/hemisphere lights and shadows.
- WebSocket client: `HELLO`, 20 Hz `INPUT`, `WELCOME` / `STATE` / `KEYFRAME` /
  `REJECT` / `ERROR` handling, 3 s reconnect.
- Responsive canvas and pixel-ratio cap.
- DOM overlays for the T00A hint card, resource readout and tooltips.

## Config

`config/render.json`, `config/controls.json` and `config/ui.json` are still
`values: {}` stubs. The current camera limits, input keys and colors are
hardcoded in `apps/client/src/main.ts`, which is a RULE_3 gap C01 must close.

## Manual verification

- `pnpm dev`, open `http://localhost:4173` in two tabs.
- Both tabs connect over WebSocket; movement is visible in both.
- Orbit, pan and zoom work; the canvas resizes with the window.
- Console is free of WebGL/shader errors after `7d22644`.

## Known limitations

- No interpolation between server ticks; cubes jump to the latest state.
- No input abstraction, rebinding, touch controls or settings UI.
- No quality tiers, dynamic resolution, object pools or debug overlay.
- The resource readout shows placeholder `0.00` values until the server sends
  resource data.
- The hint card auto-hides; it is not manually dismissible.
- `apps/client/scripts/serve.mjs` and `copy-static.mjs` are legacy helpers and
  are not used by `pnpm dev` or the deploy workflow.
