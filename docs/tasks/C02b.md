**Scope:** GPU-driven plant rendering path with compute culling/LOD, real WebGPU

**Owner:** `config/render.json`

## 1. Implementation Summary (v1 slice + impostor baking + VRAM pool + GPU skinning + texture arrays)

1. **Device and fallback plumbing**
   - `WebGPUDevice.ts` requests an adapter/device, filters required features and
     limits, configures the canvas, and reports device loss.
   - `main.ts` probes `navigator.gpu` and `webgpu_enabled`, creates a separate
     transparent WebGPU canvas over the existing Three.js canvas, and falls back
     to WebGL2 when WebGPU is unavailable. Device loss disposes the WebGPU path
     and returns to WebGL2 without recursive callbacks.
   - WebGL keeps rendering the C03 environment (sky, terrain, weather) while
     WebGPU draws plants on the overlay.

2. **GPU buffers and shader loading**
   - Frame uniforms (92 floats / 368 bytes), per-plant storage buffer (48-byte
     stride), and per-plant render output buffer (16-byte stride) are allocated
     and updated per frame.
   - WGSL is imported through Vite `?raw` from `shaders/common.wgsl`,
     `cull.wgsl`, `mesh.wgsl`, `billboard.wgsl`, and `impostor.wgsl`.
   - `vite-env.d.ts` declares the `?raw` module type.

3. **Compute-driven culling and LOD**
   - A compute pass evaluates each plant against the camera frustum and projected
     pixel size.
   - Tier assignment uses promote/demote hysteresis and a minimum dwell time so
     plants do not oscillate between tiers.
   - Tiers 0/1 select the merged mesh path; tiers 2–4 select the billboard path.

4. **Mesh and billboard passes**
   - `PlantMeshBuilder.ts` builds procedural tapered tubes and leaf cards per
     plant, grouped by root, with growth easing and plant bounds/colors.
   - `mesh.wgsl` draws tier 0/1 merged geometry.
   - `billboard.wgsl` draws camera-facing quads for tiers 2–4.
   - Sun direction, growth, health tint, and the Root Sight highlight are applied
     in the GPU passes.

5. **Impostor baking (IMPLEMENTED 2026-11-10)**
   - `IMPOSTOR_ATLAS_SIZE = 1024`, 8 horizontal × 2 vertical views = 16 views/plant
   - Atlas texture, sampler, pipeline, uniform buffers created in `WebGPURenderer.initialize()`
   - `bakeImpostors()` reads render data via `readRenderData()` to identify billboard-tier plants (tier 2-4)
   - Renders 16 views per plant to a 2D texture array (16 layers), then copies each layer to the atlas sub-rectangle using `copyTextureToTexture`
   - Billboard shader (`billboard.wgsl`) samples impostor atlas based on camera angle and plant's atlas slot
   - Impostor slot lookup buffer (`impostorSlotsBuffer`) maps plant index → atlas slot (x,y)
   - Bakes up to 4 plants per frame, prioritized by projected size

6. **VRAM pool allocation/budgeting (IMPLEMENTED 2026-11-10)**
   - `VRAMPool` class tracks allocated bytes against configurable budget (default 256 MB)
   - All buffer allocations go through `vramPool.allocate()` with budget enforcement
   - `allocateOrThrow` helper guarantees non-null buffers or throws descriptive error
   - Pool destroyed on renderer cleanup
   - Config tunables: `vramBudgetBytes`, `vramMaxVertexBytes`, `vramMaxIndexBytes`

7. **GPU skinning for 0.9s emergence animation (IMPLEMENTED 2026-11-10)**
   - Vertex buffer now includes 4 joint indices (u32x4) + 4 joint weights (f32x4) = 19 floats = 76 bytes/vertex
   - `PlantMeshBuilder` assigns joint indices/weights per segment for tapered tubes and curved tubes
   - `mesh.wgsl` and `impostor.wgsl` apply skinning via `jointMatrices` storage buffer
   - `writeJointMatrices()` computes identity matrices per joint; growth animation driven by vertex `spawnTime` + `growthProgress`

8. **Texture arrays for plant variation (IMPLEMENTED 2026-11-10)**
   - 5 texture arrays (2D array textures): Bark, Leaf, Flower, SporeSac, Seed — each 256×256×8 layers
   - Procedurally generated at startup with seeded RNG per layer (bark streaks, leaf veins, flower petals, spore bumps, seed teardrop)
   - Vertex packed data includes 4-bit `variationIndex` (bits 25-28) per vertex
   - `mesh.wgsl`, `billboard.wgsl`, `impostor.wgsl` sample from appropriate array based on `nodeType` and `variationIndex`
   - New bind group bindings 3-7 for texture arrays, binding 8 for shared sampler

9. **Debug and verification hooks**
   - `window.__plantLegacy.webgpuRenderer` exposes the renderer.
   - `readRenderData()` asynchronously reads back the render buffer for tier,
     projected size, and visibility checks.

## 3. Config Tunables (`config/render.json`)

| Tunable | Type | Range / Options | Default | Effect |
|---|---|---|---|---|
| `webgpu_enabled` | boolean | `true` / `false` | `true` | Enable the WebGPU path when the browser supports it; otherwise use WebGL2 |
| `webgpu_max_plants` | integer | [1000, 20000] | 10000 | Capacity of the plant/render storage buffers |
| `webgpu_tier0_threshold` | integer | [100, 500] | 300 | Projected pixel size at or above which tier 0 (full mesh) is used |
| `webgpu_tier1_threshold` | integer | [40, 150] | 80 | Projected pixel size at or above which tier 1 (mid mesh) is used |
| `webgpu_tier2_threshold` | integer | [6, 30] | 12 | Projected pixel size at or above which tier 2 (billboard) is used |
| `webgpu_tier3_threshold` | integer | [1, 8] | 2 | Projected pixel size at or above which tier 3 (billboard) is used; below it uses tier 4 |
| `webgpu_hysteresis_promote` | number | [1.0, 1.5] | 1.15 | Multiplier applied before promoting to a higher-detail tier |
| `webgpu_hysteresis_demote` | number | [0.5, 1.0] | 0.85 | Multiplier applied before demoting to a lower-detail tier |
| `webgpu_min_dwell_time` | number | [0.1, 2.0] | 0.5 | Minimum seconds a plant stays in a tier before changing |
| `webgpu_impostor_enabled` | boolean | `true` / `false` | `true` | Enable impostor baking for billboard-tier plants |
| `webgpu_impostor_update_interval_ms` | integer | [1000, 60000] | 5000 | Minimum time between impostor atlas updates |
| `vram_budget_bytes` | integer | [64MB, 1GB] | 256MB | Total VRAM budget for all WebGPU buffers |
| `vram_max_vertex_bytes` | integer | [16MB, 256MB] | 64MB | Maximum vertex buffer allocation |
| `vram_max_index_bytes` | integer | [4MB, 64MB] | 16MB | Maximum index buffer allocation |
| `webgpu_texture_array_size` | integer | [64, 512] | 256 | Resolution of each texture array layer |
| `webgpu_texture_array_layers` | integer | [4, 16] | 8 | Number of variation layers per texture array |

## 5. Acceptance Criteria Not Yet Met

The task remains `[ ]` until the following are implemented and verified:

- **Cross-fade between adjacent tiers** — Hard tier switches pop visually. Need
  alpha blend between tiers using dwell progress in render pass.
- **L2/L3 plant mutation rendering** — Mutation params exist in config/uniforms
  but shaders don't apply them. Need mutation logic in `mesh.wgsl`/`billboard.wgsl`.
- **Shared depth between the WebGPU plant pass and the WebGL environment pass**
  — WebGPU creates its own depth texture; WebGL terrain has no access. Plants draw
  over terrain. Options: (a) render terrain in WebGPU, (b) copy depth via
  `copyTextureToTexture` + readback (slow), (c) use WebGL for everything.
