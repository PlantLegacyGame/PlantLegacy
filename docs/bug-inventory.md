# Bug inventory

The current defect list, with the evidence for each entry. Evidence is a test,
or a **committed** capture sitting directly in
[`docs/verify/`](./verify/README.md): a browser pass's dump
(`docs/verify/pass-YYYY-MM-DD/`), a root-level `*.png` or anything in `screens/`
or `screenshots/` is gitignored, and must not be cited. This is the single home
for *what is broken now*; the order to fix it in is
[`bugfix-plan.md`](./bugfix-plan.md) (verified 2026-11-16, defect by defect) and
[`improvement-plan.md`](./improvement-plan.md) (value ranking), the programme is
[`PlantLegacy-Abyssal-Integration-Plan.md`](./PlantLegacy-Abyssal-Integration-Plan.md),
and what a fix must not break is `DESIGN.md`.

**Status legend:** `[x]` fixed and verified, **or withdrawn as not a defect**
(the row says which), `[~]` reproduced, not fixed, `[ ]` confirmed by reading the
code, `[?]` suspected, needs the browser bot.

Last updated 2026-11-16, after a full pass over the tree and the gate; see
[`bugfix-plan.md`](./bugfix-plan.md) §0 for the commands and their results. The
same day the gate was greened (L1, F10, F11 fixed), A2/A8 were fixed with
tests, and A14 was found and fixed in an in-game pass on a slope.

## Root Sight

The system is a shader illusion over a single-surface world. `ground.ts` discards
soil fragments in a cone and `cavityBowl.ts` drops an inverted shell behind them;
there is no solid earth to look into, so there are no strata to reveal.
